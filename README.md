## 🔑 安全通行認證機制

- 進入系統時，需通過安全通行密碼驗證。
- **通行密碼**：`nato`（支援大小寫不拘與空白修剪）。
- 登入狀態於本地瀏覽器持久化儲存（`localStorage`）。
- 導覽列右上角提供「🔒 鎖定」按鈕，方便隨時鎖定系統或重新測試門禁機制。

## 📖 專案背景與教育理念

「教育不該只有標準樣態，學習應激發好奇、引導思考，透過 AI 與創新教學，讓每個孩子找到最適合的學習方式！」

本專案由新竹縣康乃薾國中自然科 **簡子惠老師（Leona）** 主導建置，將多年耕耘的 **「學思達教學法」** 與 **「生成式 AI（Edcafe AI、ChatGPT、MixerBox AI）」** 深度融合，並結合日本東大生上田涉親證的 **「耳聽學習法」**，打造一套兼具**「課前聽覺預習」**、**「課中 AI 夥伴引導」**、**「課後形成性評量」** 與 **「概念圖統整」** 的全方位差異化教學閉環系統。

## ✨ 系統亮點與互動功能

1. **🔐 安全防護門禁**：
   - 門禁驗證密碼 `nato`，支援顯示/隱藏切換、錯誤動畫震動提示、記住解鎖狀態與隨時重新鎖定。
2. **🎧 耳聽學習法音訊播放器**：
   - 內建國一生物、國二理化、國三理化、國三地科與科普導聆範例。
   - 支援播放/暫停、時間進度拖曳、音量控制與 1.0x / 1.25x / 1.5x 倍速切換，搭配 Web Speech API 語音朗讀。
3. **💬 AI 智能學習夥伴【小惠】互動引導器**：
   - 模擬小惠「不直接給答案、透過提問與生活比喻啟發思考」的學思達對話模式。
   - 內建 4 組常見情境快選按鈕（細胞分裂、生殖比喻、考前衝刺、透鏡成像）與自訂輸入。
4. **📋 Prompt 一鍵複製器**：
   - 提供個人化學習（基礎/進階/高階）、遊戲式學習（角色扮演/偵探推理/快問快答）與評量診斷等 9 大通用指令，一鍵秒複製並跳出 Toast 提示。
5. **🔍 全站即時全文搜尋**：
   - 按鍵盤 `/` 鍵即可快速定位搜尋列，即時過濾所有章節卡片、實作任務與教學文章。
6. **🖼️ 圖片燈箱（Lightbox）**：
   - 點擊任何學生手寫作業或成果照片，即可彈出高解析全螢幕燈箱放大檢視。
7. **🌓 深色 / 淺色雙色主題**：
   - 支援護眼深色模式與清新明亮淺色模式，並自動保存於瀏覽器設定。
