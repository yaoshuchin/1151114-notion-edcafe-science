# 初賽-2022.12.01
![](https://s3-us-west-2.amazonaws.com/secure.notion-static.com/9e053947-4d2d-439c-81b6-d8a5b7f8e217/Untitled.png)
月考完隔天就是班際籃球賽，沒有什麼可以再練習的機會。
先謝謝代表班上上場的孩子。
女生先上場，雖然不敵對手的神準投籃，最後以2：8 敗北，但男生後來扭轉劣勢，最後以 20：14 贏得勝利！他們超級帥氣的啦~
輸贏是一回事，其實今天的比賽過程讓我覺得有特別感動的地方。
第一、女籃上場時，因為對手班有個孩子在比賽的過程中摔倒了，班上的女生不顧還在比賽，全因擔心她受傷而都停下來看著，時間彷彿停止直到大家想起還在比賽中，才又繼續進行。
第二、男生剛上場時，因追球壓力大被對手班先搶進一球時驚呼不已。但班上一個女孩默默地說：「要相信男生啊~」這時大家全心為男孩們集氣，最後果真贏得最後勝利！
真的很有愛啊~~身為導師覺得很驕傲。802很棒！

# 四強賽-2022.12.15
先說結論。班際籃球賽最後逆轉勝、從女籃 2：13，到男籃 22：15。
追的辛苦、但不推卸責任、不放棄、隊友互信不獨大，值得讚賞。
直到比賽結束以 15：15 平手，再延長 3 分鐘，最終贏得勝利。
身為這群孩子的導師，實在感到非常驕傲！
