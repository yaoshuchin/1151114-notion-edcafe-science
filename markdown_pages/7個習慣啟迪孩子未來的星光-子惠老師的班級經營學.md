# 7個習慣，啟迪孩子未來的星光-子惠老師的班級經營學

    > /icons/megaphone_gray.svg <span class="highlight-default">**緣起**</span>
      <span class="highlight-default">教育的目的不僅在培養學生應試的能力，更在於培養孩子成為未來優秀公民所需的多方面素養。然而，我們是否真能夠實現這樣的理想呢？</span>
      <span class="highlight-default">在學校中，學生投入大部分的時間學習，深受教師和校園文化的影響。然而，學習態度、生活紀律以及人際合作能力等關鍵素養，並未得到充分教授，更不是考試的範疇。</span>
      <span class="highlight-default">2021 年有幸參與 </span><span class="highlight-brown">**[沛德國際教育機構](https://www.peducation.com.tw/7hclassroom)**</span><span class="highlight-brown">** **</span><span class="highlight-default">的第三屆 7 個習慣國中高前導計畫。讓我深入了解 7 個習慣的核心價值，與108課綱所提倡的「自發、互動、共好」的理念不謀而合。</span>
      <span class="highlight-default">身為導師，希望以「身教」、「境教」和「言教」為途徑、藉由 7 個習慣的引導，有系統強化班級經營能力，完備孩子面對未知挑戰所需的品格和素養，在未來能順利成功。</span>
      <details><summary><span class="highlight-default">**實施內容與方法**</span></summary>
        ### <span class="highlight-default">【聯絡簿】</span>
        <span class="highlight-default">善用每天的都會撰寫的聯絡簿，除了進行直接教學的學習單撰寫之外 (例如 </span><span class="highlight-brown">**[7個習慣簡介](/1c6454c564234a8785def8546505bb9e?pvs=25)**</span><span class="highlight-default">)，也會訓練孩子有效規畫時間 (</span><span class="highlight-brown">**[聯絡簿每日讀書計畫](/457d6797d4b640d1a14ae3dc3af6056e?pvs=25)**</span><span class="highlight-default">、</span><span class="highlight-brown">**[高效學習原子習慣的讀書計畫](/f821f568ac2b44cf804843b61f91ff91?pvs=25)**</span><span class="highlight-default">)。</span>
        ### <span class="highlight-default">**【身教】**</span>
        <span class="highlight-default">藉由導師以身作則，用實際的行動和榜樣的展示，和孩子們分享並產生影響。</span>
        - <span class="highlight-default">刻意、持續使用正向語言與孩子溝通，不輕易指責。</span>
        - <span class="highlight-default">導師的使命宣言：成為更有愛的人，幫助學生成功。</span>
        - <span class="highlight-default">在繁忙的公務及家務中，如何有效利用時間來完成每件重要的事情。</span>
        - <span class="highlight-default">學習單分享、7 個習慣的公開分享，再藉由老師們的回饋再度修正。</span>
        - <span class="highlight-default">利用假日不間斷的進修研習，終身學習。</span>
        - <span class="highlight-default">挑戰教案比賽，持續獲獎。</span>
        ### <span class="highlight-default">**【**</span><span class="highlight-default">**[境教](/303acfe896794a40b0d2e9c9c6170f76?pvs=25)**</span><span class="highlight-default">**】**</span>
        <span class="highlight-default">國中三年，在教室中佈告欄中張貼「領導力工具圖」、「7 個習慣樹」、「個人使命宣言」、「班級使命宣言」、「優缺點分析圖」、「月考目標計畫牆」、「教育會考目標計畫牆」、「時間矩陣圖」、「領導力角色清單」等。隨時提醒孩子，有用才有用！</span>
        ### <span class="highlight-default">**【言教】**</span>
        <span class="highlight-default">**依賴期：國一是品格啟蒙時期，利用每週的彈性時間及導師時間，結合自我探索及7個習慣的直接教學，以培養孩子自主行動，擁有學習與創造的熱情。**</span>
        - <span class="highlight-default">習慣一主動積極：想讓孩子認識自己、發掘自己的價值與潛能。</span>
        <span class="highlight-brown">**[發現自我](/46fa5c3d74a24bb69a6e8ecf473808fb?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[角色樹](/3e34720e65c24533bb119618ee9bc305?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[學會使用正向的語言，及專注在自己的影響圈](/f6d8ec257e024e0d82df8e55cf83a85a?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[考後自我檢視](/d1a2e139a40b4933be7105981be06807?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[幹部志願履歷](/e41b498ff5a14d979930ee8772b92bcb?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[自己的分數自己賺](/3ed42d8617bf432dbaa3496ef92bc191?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[領導力角色反思](/c70675ad20c9451887ee631a384fbdb8?pvs=25)**</span>
        - <span class="highlight-default">習慣二以終為始：想想看，我們想要活出怎麼樣的人生呢？</span>
        <span class="highlight-brown">**[個人使命宣言](/7496dee137d54875b2ebc5e3e278943e?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[班級使命宣言](/585f3306f93a48a1b405570c4ae7733b?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[夢想無距、無懼築夢](/49ffbc5356624a33b35f89a5df474620?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[夢想九宮格](/46f6feb874cc4f6e80fb7e38a27d6a4a?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[2021~2022年度代表字](/0230f5f9d91d47a9a9cf9b010e13e8b3?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[2023年度代表字](/df256f897d0a4030997272232d0add11?pvs=25)**</span><span class="highlight-default">；選擇學習目標 (</span><span class="highlight-brown">**[考前目標計畫表](/4b5f01f25cae48b98acaf8709758aed6?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[自訂國三會考目標](/57fc75be0c3642e98fb40e393c5a03f9?pvs=25)**</span><span class="highlight-default">)</span>
        - <span class="highlight-default">習慣三要事第一：學會該如何聰明地分配時間和資源？</span>
        <span class="highlight-brown">**[學會安排每週計畫](/f821f568ac2b44cf804843b61f91ff91?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[專注於最優先的事情](/e13ebf86706d40d69d42b532238b08a4?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[「學習」是很重要的事](/0165592b8ed34887807f7801095ea08d?pvs=25)**</span><span class="highlight-default">；</span><span class="highlight-brown">**[歸納優良的學習習慣、態度、方法及成效](/ca65050ebe404b18a04c4485dd37fcf4?pvs=25)**</span>
        ### <span class="highlight-default">**【校園生活中的自我領導力實踐】**</span>
        <span class="highlight-default">**獨立期：當個人成功的基礎打穩了之後，接下來要學習與他人溝通合作、建立情感帳戶，創造出更多可能，成為一個出色的領袖。**</span>
        - <span class="highlight-default">習慣四雙贏思維：在各種情境中考慮自己和他人的贏。</span>

        - <span class="highlight-default">習慣五知彼解己：期待孩子能了解自己的優點、學會傾聽、理解並同理他人。</span>
